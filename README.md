# quanttide-strategy

量潮战略管理

## 概述

quanttide-strategy 是量潮战略管理领域，涵盖战略规划、战略解码、战略执行与战略评估等全链路管理实践。

## 领域边界

- **战略规划**：愿景使命、外部洞察与战略选择
- **战略解码**：目标拆解、行动策略与资源配置
- **战略执行**：落地机制、组织协同与过程管控
- **战略评估**：效果度量、复盘迭代与动态调整
